# Feedback - Anna - 2026-07-15

## Source

Anna feedback provided via pasted text on 2026-07-15.

## Context

Feedback covers the Digital Quote Builder interface, smaller-screen usage, Step 2 problem cards, Live Scan Summary, Page 3 insight level, Page 4 ROI model, German translation, and final export/follow-up.

## Raw Feedback

### 1. Usage and Interface

On smaller screens and multi-device setups, some elements currently overlap. This should be tested properly across different screen sizes, including mobile. The text in the dark box also feels quite compressed, so we should check readability and alignment with the PFM CI.

In some areas, the page scrolls into empty white space, which makes the tool feel unfinished. This should either be made static or visually contained. We should also consider using more professional icons or graphics instead of the current AI-style icons, so the look and feel fits better with the PFM brand.

On page 2, there is currently too much scrolling. It would be better to show only the headlines of the problem cards first, with details available via an expandable section or an info icon with mouse-over. The top navigation should also not be freely clickable if required information from earlier steps is still missing. A greyed-out state or a short message would help guide the user more clearly.

### 2. Segments and Input Fields

For the segments, we should check whether "Footwear" should actually be part of Fashion. I would also add "Books & Toys" and possibly "Beauty & Wellness", especially considering customers such as dm, Douglas, or MAC.

We should also consider adding "Event" as a third option. It is similar to Shopping Center in some ways, but it has its own complexity and should probably be handled separately. We are also seeing more requests in this direction.

For Retail, I would additionally ask for the number of entrances and whether the store has multiple floors.

### 3. Content and Problem Card Wording

The cards on page 2 should sound more like customer language and less like feature mapping. The goal should be that the customer immediately recognises their own situation.

Example:

"Families and groups make conversion look worse" is not ideal because it implies that the customer already knows or measures this segmentation. A better wording would be:

"Groups distort our conversion figures."

In general, the logic should be:

Not: "Which PFM insight categories fit?"

But: "Which problems does the customer recognise from their daily business?"

The cards should sound like statements a retail leader would actually say, not like PFM is already embedding the solution into the question.

### 4. Live Scan Summary

I really like the idea of the Live Scan on the right-hand side. However, it currently becomes cluttered quickly when several topics are selected. The selected topics visually pile up and become hard to read.

The wording "Live Scan Summary" together with "Company" and "Retail Chain Performance Scan" also feels repetitive and not very meaningful. A better label could be "Performance Insights Menu" or "Selected Challenges."

It is also important that this area clearly shows either the selected problems or the potential solutions, but not a mix of both. I would also remove the icons here, as they make it feel too playful.

"Realistic Gain €0" should not be shown before there are enough ROI inputs. Before that, a better message would be:

"Potential will be calculated in the next step."

Later, the Live Scan could be developed more strongly into a "You will receive ..." logic, using green checkmarks. This would give the customer a stronger sense of progress and clearly show which solutions or KPIs are covered by the selected route.

### 5. Page 3: Insight Level

The sentence below the headline currently feels a bit unnatural:

"This is the practical insight level: what PFM makes visible, explainable and improvable across stores."

A better version would be:

"This is the practical insight level: it makes visible, explainable and optimizable what PFM delivers across stores."

From a content perspective, I would expect page 3 to show more solutions and answers. At the moment, some elements still feel like questions directed at the customer, for example: "Do you know how many visitors are needed for today's revenue?" That does not fully match the promise of "Insights." This page should more clearly show which concrete answers PFM provides.

### 6. Page 4: EUR Impact Model and ROI

On my Mac and second screen, some graphic boxes overlap with the ROI control elements. Because of this, I cannot properly test the ROI calculation, as not all areas are visible.

In the "Extended Scope and Pricing Assumptions" section, some numbers appear twice: once in the manual input field and once next to the headline. This feels unnecessary. The columns should also expand more horizontally rather than vertically; the current distorted layout or graphic is probably causing this issue.

In general, this page uses many abbreviations and technical terms. An info box explaining abbreviations and assumptions would help a lot. The "Realistic Gain" appears properly for the first time here and should be visually highlighted more clearly, for example with green/red colouring, so the user immediately understands what has changed.

### 7. Language and German Translation

The German translation should be reviewed again in full. Some formulations still feel like AI-generated translations and are not natural enough for a professional customer conversation. This is especially important for headlines, problem cards, buttons, and ROI explanations.

### 8. Export and Follow-up

On the final page, there should be an option to print the result in PFM CI or send it by email. For email delivery, we should include consent wording that the email address may be stored in the CRM and that PFM is allowed to follow up.

## Conclusion

You know my opinion - The overall concept is strong! To make it really work in a sales context, we need to make the questions more customer-centric, structure the summary more clearly, fix the ROI page layout, and polish the German language so it sounds professional and natural. Perhaps the other languages too I think, depending on the country.
