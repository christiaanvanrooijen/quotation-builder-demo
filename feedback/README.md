# Feedback Structure

This folder is the official feedback workspace for the Digital Quote Builder.

## Folders

- `inbox/`: raw feedback inputs such as emails, markdown notes, PDFs and screenshots. Treat these as source material.
- `triage/`: processed summaries, duplicate maps and prioritised backlog.
- `decisions/`: proposed or approved decisions based on triaged feedback.

## Rules

- Add new raw feedback to `feedback/inbox`.
- Keep processed analysis in `feedback/triage`.
- Keep approved or proposed decision records in `feedback/decisions`.
- Do not edit application code as part of feedback filing or triage.
